Gait Pattern Characterization Tool

This Python tool was developed for my Bachelor's Thesis in Biomedical Engineering at San Pablo-CEU University (2023). It analyzes the hip flexion/extension Range of Motion (ROM) signals recorded by the SWalker robotic platform, which is designed to rehabilitate elderly patients after a hip fracture. From those signals it calculates cadence, step and stride length, step, stride, support and swing times, single and double support times, and walking and stride speed. As a result, physiotherapists get useful information beyond the raw range of motion, which helps them design more specific sessions and monitor the patient's progress. Step width could not be measured because the data only covers the sagittal plane.

COVID_APP

A Java application with an SQL database that estimates COVID-19 mortality risk from clinical and demographic data. It was developed with a four-member team in weekly sprints. My part was the backend: designing the SQL tables, implementing the terminal-based functionality in Java (including the data queries), and enabling data export and import between SQL and HTML.

Modern Hopfield Networks on CIFAR-10

Final project for the Deep Learning course (CSCI 1470) at Brown University, Spring 2025. We built a TensorFlow-based Modern Hopfield Network in Python and evaluated it on the CIFAR-10 dataset. The goal was to use associative memory dynamics to restore corrupted images, reconstructing the original image from a damaged version.
